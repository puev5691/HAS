# Антенное поле и защитный колпак — КОМПАС-3D

Рабочий снимок от 28 ноября 2026 года. Модели относятся к экспериментальному стенду и защитному колпаку из PETG. Разработку выполняли в КОМПАС-3D v21.

## Открытие и восстановление

1. Скачайте репозиторий целиком через Code → Download ZIP или клонируйте его, затем распакуйте ZIP.
2. Все файлы внутри папок `cover` и `field` оставьте рядом друг с другом, имена не меняйте.
3. Для секционного колпака откройте `cover/Сборка_колпака.a3d`. В этой сборке 12 деталей с интегральными клеевыми нахлёстами без отдельных накладок. Закрытый торец тоже имеет нахлёсты.
4. Для антенного поля с монолитным компоновочным колпаком откройте `field/Сборка_антенного_поля_восстановление.a3d`. Она пересоздана из пяти компонентов с сохранением их положений, чтобы файлы находились рядом. Это восстановительная копия, а не замена исходной параметрической сборки и её связей.
5. Исходные сборки антенного поля сохранены в `field`: они могут содержать старые абсолютные пути и потребовать повторного указания компонентов в КОМПАС. Здесь же сохранены обе версии площадки, детали антенн, монолитный колпак и первоначальная компоновка уплотнения.

Проверка переноса: обе восстановительные сборки открыты в КОМПАС из других каталогов, все 12 секций и все вложенные компоненты антенного поля найдены в соответствующих перенесённых папках. Это не проверка восстановления на другом компьютере или другой версии КОМПАС.

## Состояние конструкции

Пользователь посмотрел сборку секций и предварительно подтвердил компоновку. Сборка остаётся опытной: геометрические пересечения, непрерывность клеевых поверхностей, порядок склейки, доступ к восьми саморезам и прочность не проверены. Номинальный зазор 0,2 мм — исходное допущение, клей ещё не выбран и не испытан. Проверки печати, атмосферостойкости и влияния колпака на антенны не выполнялись. При добавлении компонентов API вернул Update=False, несмотря на успешные перестроение и повторное открытие; причина не исследована.

## Целостность и ограничения

В `SHA256SUMS.txt` перечислены контрольные суммы моделей. Это снимок, не автоматическая синхронизация: последующие изменения нужно отдельно отправлять в репозиторий. КОМПАС и лицензия в состав не входят. Для большей устойчивости имеет смысл иметь ещё одну независимую копию.
