# Helix Production

### Parametric Helical Antenna Generator for OpenSCAD

Helix Production — это параметрический конструктор геликальных антенн, реализованный на **OpenSCAD**.
Проект предназначен для расчёта, моделирования и подготовки печатных деталей для сборки **осевой геликальной антенны (Axial Mode Helix)**.

Модель автоматически масштабируется по частоте и позволяет генерировать как геометрию антенны, так и механические элементы конструкции.

---

# Основные возможности

* параметрическое проектирование геликальных антенн
* масштабирование геометрии по частоте
* автоматический расчёт длины волны
* генерация креплений и монтажных элементов
* экспорт отдельных печатных деталей
* генерация оснастки для сборки

---

# Концепция конструкции

Антенна состоит из трёх типов элементов.

## Электрические элементы (не печатаются)

* спираль из медной проволоки
* согласование **Delta Match**
* RF-разъём (SMA или N)

## Механические элементы (печатаются)

* основание антенны
* держатель трубы намотки
* крепление к рефлектору
* крепление к поверхности

## Оснастка

* jig для гибки delta-match

Спираль формируется **намоткой проволоки на трубку**, а не печатью.

# Архитектура проекта

Типичная структура файла:

```
helical_antenna.scad

1. Global parameters
2. Frequency / wavelength calculations
3. Helix geometry
4. Delta match geometry
5. Reflector + connector
6. Mechanical mount
7. Wall mount
8. Delta bending jig
9. Export parts
```

---

# Основные параметры

## Частота

```
frequency
```

Используется для вычисления длины волны

```
λ = c / f
```

---

## Геометрия спирали

```
helix_diameter
helix_pitch
turns
helix_length
wire_diameter
```

Часть параметров может вычисляться автоматически.

Количество витков ограничено диапазоном

```
5.5 ≤ turns ≤ 14
```

---

# Согласование антенны

Используется **Delta Match**.

Начальная геометрия:

```
base ≈ 0.18 λ
height ≈ 0.10 λ
tap ≈ 0.045 λ
```

Это стартовая эмпирика, которая может корректироваться после измерений.

Для точной настройки используются коэффициенты:

```
delta_k_base
delta_k_height
delta_k_tap
```

---

# Подключение разъёма

Разъём устанавливается на металлический рефлектор.

```
центр разъёма → delta match
корпус разъёма → рефлектор (земля)
вершина треугольника → начало спирали
```

# Печатные элементы

## Основание антенны

Функции:

* удержание трубы намотки
* центровка спирали
* крепление к рефлектору

---

## Крепление к поверхности

Содержит:

* четыре монтажных выступа
* сквозные отверстия под саморезы

---

# Оснастка для гибки Delta Match

Проект содержит печатный **jig**.

Назначение:

* точная гибка медной пластины
* повторяемая геометрия согласования

Этот элемент используется только при сборке.

---

# Генерация спирали

Спиральная канавка строится через

```
hull() между сферами
```

Это позволяет получить гладкую геометрию без ломаных сегментов.

---

# Режимы экспорта

Модель поддерживает экспорт отдельных деталей.

```
export_part
```

Например

```
0 preview
1 antenna base
2 wall mount
3 delta jig
```

# Минимальная частота применения

Модель рассчитана на диапазон примерно

```
350 MHz – 5800 MHz
```

На низких частотах конструкция требует повышенной механической жёсткости.

---

# Требования

* OpenSCAD
* 3D-принтер
* медная проволока
* медная пластина для delta-match
* металлический рефлектор

---

# Сборка антенны

1. распечатать механические детали
2. установить RF-разъём в рефлектор
3. согнуть delta-match
4. намотать спираль на трубку
5. припаять согласование
6. закрепить конструкцию

---

# Цель проекта

Создать **универсальный параметрический конструктор геликальных антенн**, позволяющий быстро проектировать и изготавливать антенны для различных диапазонов частот.
