# Атлас цилиндрических винтовых антенн

Статический учебный атлас с геометрическим калькулятором и реестром источников. Публикуется в GitHub Pages из ветки `gh-pages` репозитория HAS.

Для локального просмотра запустите `python -m http.server 8088` в этой папке и откройте `http://localhost:8088/`. Проверки вычислений: `node --test tests/geometry.test.mjs`.

Расчёты относятся к идеальной геометрии и не подтверждают характеристики построенной антенны.
