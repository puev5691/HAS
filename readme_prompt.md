=== ЦЕЛЬ ===

Создать стабильный, производственный OpenSCAD-файл, который:

1) Генерирует осевую геликальную антенну от заданной частоты.
2) Автоматически рассчитывает все геометрические параметры.
3) Делит корпус на печатные секции.
4) Использует внутренние соединительные кольца.
5) Содержит узел питания с SMA-female (4 винта).
6) Генерирует рефлектор.
7) Генерирует центральную втулку.
8) Генерирует коаксиальный монтажный кронштейн.
9) Выводит расчётные размеры металлических элементов через echo().
10) Рендерится без CGAL-ошибок.


=== РАДИОРАСЧЁТ ===

Частота f (МГц).

λ = 300000 / f

Диаметр спирали:
D ≈ λ / π
R = D / 2

Шаг спирали:
spacing = λ * pitch_factor

Режимы:
compact = 0.18
standard = 0.23
quarter = 0.25
manual

Количество витков:
turns = max(5.5, pow(10, (G - 5.4)/10))

НЕ округлять до целого.

Длина прутка:
L = sqrt((πD)^2 + spacing^2) * turns

Диаметр прутка:
wire_d = λ * k
режимы: 0.01 / 0.02 / 0.03 / manual


=== КОРПУС ===

Толщина стенки:
wall >= groove_depth + 1.5 мм
wall >= 0.015 λ

Автоделение:
max_section_height = 180 мм
section_count = ceil(total_height / max_section_height)

Каждая секция:
полый цилиндр

Между секциями:
внутреннее соединительное кольцо
длина = 10% высоты секции (не менее 10 мм)
толщина = wall

Кольцо:
половина встроена в нижнюю секцию
половина выступает внутрь следующей


=== ЦЕНТРАЛЬНАЯ ВТУЛКА ===

Втулка — отдельная деталь.

Кольцевой выступ выходит из основания втулки.
Он входит внутрь первой секции трубы плотно.

Втулка НЕ нагружает SMA.


=== РЕФЛЕКТОР ===

Диаметр = 0.75 λ
Толщина >= 2 мм

Отверстие под трубу по центру.

SMA-female (4 винта):
расположен за радиусом трубы
offset = body_radius + 8 мм
центральное отверстие ≈ 6.5 мм
4 крепёжных отверстия 3.2 мм


=== СОГЛАСУЮЩИЙ ТРЕУГОЛЬНИК ===

НЕ моделируется.

Вывести размеры:

высота ≈ 0.17 λ


=== МОНТАЖНЫЙ КРОНШТЕЙН ===

Расположен коаксиально с трубой.
Крепится с обратной стороны рефлектора.

4 самореза:
проходят через рефлектор в втулку.

4 самореза:
крепят кронштейн к монтажной плоскости.

Кронштейн не несёт нагрузку SMA.
